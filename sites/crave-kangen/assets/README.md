## The "expensive but real" treatment applied to each

Every photo is framed identically so the set reads as one commissioned shoot,
not five phone snaps:

- **Brand grade** — a subtle deep-teal duotone wash + slight desaturation, so
  the varied lighting across your photos unifies into the site's palette.
- **Full color on hover** — the grade lifts and the image gently scales, an
  editorial micro-interaction (desktop).
- **Fine grain** overlay to match the paper texture of the page.
- **Framing** — hairline border, soft ambient shadow, a whisper of a top bevel.
- **Caption** — small, letter-spaced, bottom-left over a gradient scrim.
